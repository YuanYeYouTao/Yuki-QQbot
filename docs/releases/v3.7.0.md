# Yuki 3.7.0 发布说明

Yuki 3.7.0 将群聊短期会话统一为 Bot + 群，并把旧分层 History Rollup 替换为每个 Scope 一个连续检查点。目标是让同群成员共享同一 generation、原始历史和摘要，同时保证旧 generation 的模型结果、工具与媒体效果不能越过 `/ai new` 边界。

## 主要变化

- 群聊 Actor 不再参与短期会话身份；同群不同 Bot 仍完全隔离；
- 所有主会话账本写入统一经过 scoped Unit of Work；
- 新增 `conversation_scopes`、`conversation_rollups`、`conversation_rollup_jobs`；
- Rollup 模型失败时同批次立即使用 extractive，不再形成 terminal failed job；
- `/ai new` 的入站命令事件与 generation 切换在一个数据库事务中提交；
- generation fence 与 EffectGate 覆盖模型、工具、回复、语音、图片和插件副作用；
- Rollup 和外部事件始终是不可信 input，不进入 DeepSeek `instructions`；
- 删除本地 PromptInputCache 和伪 `prompt_cache_key`，改用真实序列化前缀与 request shape 诊断；
- 删除旧 history CLI 和旧 0041 运行时表；
- Rollup 投影按 `DEFAULT_TIMEZONE` 默认的东八区显示事件时间，不再把库存 UTC 直接塞给模型；
- 出口清理会去掉模型回显的行首 `>` 引用前缀；历史 Prompt 保持落库原文，避免 DeepSeek 前缀缓存被剥引用打断。
- 插件后台回复声明与普通群聊相同的首轮工具 schema，但不执行工具，避免 0 工具请求把会话前缀缓存压回静态 instructions。
- 前台 Rollup 按 trigger/stop 滞回压缩：热尾未过 `raw_tail + trigger` 时只追加，避免 extractive 每轮重写第一条历史、把 DeepSeek 缓存打回静态 instructions。默认热尾 256、trigger 1024、stop 0；`LOCAL_CONTEXT_EVENT_LIMIT` 默认 2048。

Alembic head 为 `0042`，Plugin API 仍为 `2.0`。

## 不兼容变化

- 0042 是不可逆迁移；旧 history state、summary、member 和 job 数据不会迁入新表；
- 升级后的短期会话从每个 Scope 的迁移时账本高水位重新开始，永久 `chat_events` 与 Memory V2 保留；
- 旧 `CONVERSATION_HISTORY_*` 配置和 3.6 的分层 Rollup 配置会使启动明确失败，必须先改成新的 `CONVERSATION_ROLLUP_*` 配置；
- 群 `/ai new` 现在是全群新会话，只允许 Bot 超级管理员；
- 同一 SQLite 数据库只支持一个主动 Bot Application，禁止双活和 Compose 扩容。

## 升级与回退要点

1. 在 3.6.1/0041 上停止 Bot，一致备份数据库/WAL/SHM、`.env`、`config/`、`.mcp.json` 和当前镜像 ID。
2. 删除旧 Conversation History/Rollup 环境键，换用本发布包 `.env.example` 中的 `CONVERSATION_ROLLUP_*`，并设置 `YUKI_VERSION=3.7.0`。
3. 拉取并只重建一个 Bot 实例；启动应将数据库升级至 0042。
4. 验证 `/healthz` 版本、Alembic revision、`PRAGMA foreign_key_check`、双成员群聊、管理员群 `/ai new` 和一次强制 extractive 降级。

0042 不可 downgrade。回退时必须停止 3.7.0，恢复升级前同一时点的数据库/WAL/SHM 与配置快照，然后启动备份记录中的 3.6.1 镜像。不得在 0042 schema 上启动旧应用。

完整备份、升级、验证和回退步骤见 [3.7.0 升级指南](../upgrade-3.7.0.md)。架构合同见 [ConversationScope 与单检查点 Rollup](../architecture/conversation-rollup.md)，键族与写入点审计见 [3.7.0 会话键清单](../architecture/conversation-key-inventory-3.7.0.md)。
