# Yuki 3.5.3 发布与升级说明

Yuki 3.5.3 为版本化 Docker 部署增加 Guided Setup。它不改变 Agent、Memory 或 Plugin API，
不新增数据库迁移；Alembic head 保持 `0036`，Genie-TTS Worker 内部版本保持 `1.9.0`。

## 首次安装

仅需 Docker Engine / Docker Desktop 与 Docker Compose v2。正式支持 `linux/amd64`。

1. 从 GitHub Release 下载 `install.sh`（Linux）或 `install.ps1`（Windows）。
2. Linux 执行 `chmod +x install.sh && ./install.sh`；Windows PowerShell 执行
   `powershell -ExecutionPolicy Bypass -File .\install.ps1`。
3. 安装器下载精确的 `3.5.3` 部署包并用 `SHA256SUMS` 校验，然后拉取 Bot 镜像。
4. 按向导填写管理员 QQ、主模型配置，并选择需要的扩展能力。
5. 安装器完成 Compose 启动和健康检查后，打开 <http://127.0.0.1:6099> 登录 NapCat。

默认安装目录是当前目录下的 `yuki/`。Linux 可传 `--dir PATH`，PowerShell 可传
`-InstallDir PATH`。机器人 QQ 号由 NapCat 实际登录账号决定。

## 向导行为

- 初次安装时 Flash、Embedding、Web、Vision、MCP、Plugin、Automation、Speech 全部默认关闭。
- API Key 和 MCP 敏感 Header 不回显，不进入摘要或日志；OneBot 与 NapCat Token 自动生成。
- OpenAI-compatible Chat Completions 主模型必须支持 Function Calling。
- DeepSeek Responses 可选择模型原生搜索；请求不会发送任何 `tool_choice` 字段。
- MCP 引导只支持 Streamable HTTP。stdio Server 需要自行维护包含进程依赖的定制镜像。
- 插件只读取 Manifest 并逐项请求批准，不会为了展示选项而导入插件代码。
- Speech 不会下载模型；只有检测到非空 GenieData 与合法声线档案时才能开启。
- 验证只检查 Settings、协议、Schema 和本地文件，不会调用模型、Tavily 或其他计费 API。

若终端不支持颜色，或设置了 `NO_COLOR`、`TERM=dumb`、`CI`，向导自动使用纯文本。也可直接
执行 `qq-ai-bot-cli setup --no-color`。

## 从 3.5.2 升级

升级前备份部署目录，尤其是 `data/` 与 `.env`。

1. 从 3.5.3 部署包中只更新生产 `docker-compose.yml`、`.env.example` 和安装器；不要覆盖
   `config/`、`plugins/`、`data/`、`napcat-data/`、`napcat-config/` 或 `napcat-plugins/`。
2. 在已有部署根目录运行 3.5.3 安装器。它会识别现有部署并直接重开向导，不创建嵌套目录。
3. 选择要修改的区块。未选择区块保持不变；明确关闭功能会保留旧密钥，只关闭开关。
4. 确认脱敏摘要。受影响配置写入前会备份到 `.yuki/backups/<timestamp>/`，保留最近 5 份。
5. 安装器更新 `YUKI_VERSION=3.5.3`，执行 Compose 拉取、重建和健康检查。

也可以完成向导后手动更新：

```bash
docker compose pull
docker compose up -d
docker compose ps
```

## 手动运行 Setup CLI

部署包内没有 Python 环境；应通过正式 Bot 镜像运行向导。安装器已经封装了该步骤。容器内可用
的维护入口为：

```text
qq-ai-bot-cli setup
qq-ai-bot-cli setup validate
qq-ai-bot-cli setup apply-pending
qq-ai-bot-cli setup verify
```

`apply-pending` 仅应在 Bot 完成 `0036` 数据库迁移后运行。安装器会按此顺序执行，并且只在插件
状态实际变化时重启 Bot 一次。

## 数据与安全边界

- Setup 容器不挂载 Docker Socket，也不能自行编排宿主容器。
- 生产 Compose 仍完全使用版本化 GHCR 镜像，不包含 `build:`。
- `.env` 在 POSIX 使用 `0600`；Windows 安装器把配置与备份 ACL 限制为当前用户。
- 重跑不会删除数据库、QQ 登录数据、插件文件、语音模型或其他持久化目录。
- NapCat Token 只提示位于 `.env`，不会显示在最终状态摘要中。
